## LLM

一句话来讲，是一种能够理解和生成自然语言的基础模型，从本质上来说通过上下文预测下一个可能出现的token，但是如果需要完成其它任务则需要 **tool** 来配合完成

## Prompt

提示词，用来描述任务，提供信息，约束格式，来精确完成任务

具体还细分为`user prompt`和`system prompt`

## tool

LLM通过调用`tool`(平台方)来获取更多信息，API，外部程序....

## RAG

RAG【 ***检索增强生成*** 】 找到相关资料，连同问题一起交给LLM，让模型生成回答(不是重新训练模型，而是先检索资料，再把资料临时提供给模型)

## Agent

智能体是一个围绕目标执行任务的系统，不只是`chatbot`，而是会按步骤做事。通常而言是一个系统,Agent 通常不是单独一个模型，而是由程序流程把 LLM、Prompt、Tool、Memory 等组织起来的任务执行系统。

这个让我想起年初火起来的  ***openclaw*** ，这个Agent后来因为很多安全因素受到了许多质疑，权衡利弊是当下应该重点考虑的

### Summary

LLM自己本身负责理解和生成语言，但如果真要完成真实任务，离不开清晰的**Prompt**和**Tool**，而**Agent**则是在这些能力基础上构建出来的任务执行系统，不只是回答问题，而是围绕目标进行拆解，调用和执行。

##### Example

一个最小例子：课程资料问答系统

1. 用户输入问题
2. 系统先检索相关资料
3. 把资料和问题一起交给 LLM
4. LLM 生成回答
5. 如果后续还能继续拆任务、调用工具，就更像 Agent
